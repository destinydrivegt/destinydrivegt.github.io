# GCC Cargo Link Website

Static website for a GCC road freight brokerage company.

## Files

- `index.html` - main website page
- `styles.css` - visual design and responsive layout
- `script.js` - shipment calculator logic
- `assets/gcc-road-freight-hero.png` - hero image

## Publish With GitHub Pages

Upload these files to a public GitHub repository, then enable GitHub Pages from:

Settings -> Pages -> Deploy from a branch -> main -> /root
